# Evidencias — Nueva Funcionalidad

Esta carpeta contiene **evidencias mínimas** para trazabilidad.  
Regla: si una evidencia aplica y falta, el agente correspondiente debe marcar **REJECTED/REWORK**.

## Archivos
- `planning.md`: descomposición, dominios, flujo transaccional, riesgos, estrategia de testing.
- `code-changes.md`: mapeo plan→código, diff/archivos tocados, decisiones y desviaciones.
- `tests.md`: lista de tests creados, comandos ejecutados, output relevante.
- `qa.md`: pasos manuales reproducibles, resultados y hallazgos.
- `security.md`: checklist, riesgos y mitigaciones.
- `performance.md`: checklist, métricas/mediciones (si aplica), riesgos y recomendaciones.
